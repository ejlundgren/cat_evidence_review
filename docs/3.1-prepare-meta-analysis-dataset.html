Now we’ll meta-analyze the quantitative articles that provided data usable for a meta-analysis. We’ll start by calculating effect sizes and then converting effect sizes to a common type for analysis based on our analysis groups.

We’ll then run a suite of models and choose the model with the best random effects. Finally, we’ll plot the resulting model estimates and conduct publication bias tests.

Prepare dataset

Prepare environment

We’ll start by loading packages and some helper functions. The convert_effect_sizes function contains formulas to convert between effect sizes. The formulas were originally provided by Borenstein et al. (2021). The get_r function is a simple helper function for extracting the correlation coefficient (r) from the cor.test output.

get_r <- function(x, y){
  out <- cor.test(x, y)
  return(out$estimate)
}

z-to-r-transformed correlation coefficients (Zr) effect sizes

We’ll start with the correlation coefficient (Zr) effect sizes.

Note that several effect sizes in this dataset can be analyzed either as Zr effect sizes (with binary predictor) or SMD. We’ve decided that they would best be analyzed as SMD effect sizes, which we handle in the code below.

Because the variance of proportion data increases closer to 0/1 boundaries, we stabilized variance with arc-sin square root transformation and the delta method following Macartney et al. (2022).

Now we'll meta-analyze the quantitative articles that provided data usable for a meta-analysis. We'll start by calculating effect sizes and then converting effect sizes to a common type for analysis based on our analysis groups. 

We'll then run a suite of models and choose the model with the best random effects. Finally, we'll plot the resulting model estimates and conduct publication bias tests.

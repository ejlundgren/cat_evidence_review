In this page we will plot and analyze the citation network uncovered by following all claimant and non-claimant sources regarding the effects of cats on threatened wildlife.

Claimant sources are reviews that claimed that cats were a driver of endangerment and are treated separately than non-claimants, which included a systematic search in Web of Science along with opportunistic records found and a published systematic review (Wallach and Lundgren 2025).

This workflow is derived from a full R script in scripts/2_analysis/1 citation networks and bias.R that includes additional checks and tests and is fully interactive if you clone the repo.

The data for this analysis consists of two files, one for the nodes (e.g., each article) and one for the edges (the citations between articles). This data was prepared in scripts/1_data_mgmt/2 create network formats.R and were further pre-processed in scripts/2_analysis/1 citation networks and bias.R to be ready to be used to create our citation network.

Probability of being cited

Now, let’s evaluate the terminus of each citation chain from the core claimant sources (the large bright pink points). We used graph algorithms to identify the terminus of each citation chain, starting with the core sources (the large pink circles in the network figure above). See scripts/1_data_mgmt/3 create probability of being cited dataset.R for this code.

We then asked what proportion of those citation chains ended in population studies, e.g., empirical studies that link cats to bird abundance or reproduction ?

To do so we’ll load a separate data frame produced by this that is organized as source - citation-terminus pairs. Each row is a potential citation. The colum cited (0 or 1) indicates whether the article was cited or not. Pairs are constrained by species and publication timing (e.g., articles published after ≤6 months after claimant reviews concluded were excluded).

This dataset allows us to evaluate whether claimants cited the available evidence, and whether there was any bias in citation towards articles that found a negative association between cats and prey. We’ll do this with binomial model, to test whether the probability of a population study with data being cited (anywhere within citation chain) by claimant sources was different for studies that found a negative association from those that did not find a negative association.

The model summary table here gives a suite of information about the model fit (including AIC, BIC, log-likelihood), the amount of variance explained by each random effect (the claimant source cited_by_id and the prey species scientificName) and estimates for our coefficients. As you can see, there’s no difference between citation probability for articles “in support” (estimate = -0.37, z = -0.859, p = 0.39) (also known as finding a negative association) as for articles that did not (the Intercept).

In this page we will plot and analyze the citation network uncovered by following all claimant and non-claimant sources regarding the effects of cats on threatened wildlife. 

Claimant sources are reviews that claimed that cats were a driver of endangerment and are treated separately than non-claimants, which included a systematic search in Web of Science along with opportunistic records found and a published systematic review [@Wallach2025-ta]. 

This workflow is derived from a full R script in `scripts/2_analysis/1 citation networks and bias.R` that includes additional checks and tests and is fully interactive if you clone the repo.

# Probability of being cited
Now, let's evaluate the terminus of each citation chain from the core claimant sources (the large bright pink points). We used graph algorithms to identify the terminus of each citation chain, starting with the core sources (the large pink circles in the network figure above). See `scripts/1_data_mgmt/3 create probability of being cited dataset.R` for this code.

We then asked what proportion of those citation chains ended in *population studies*, e.g., empirical studies that link cats to bird abundance or reproduction ?

To do so we'll load a separate data frame produced by this that is organized as source - citation-terminus pairs. Each row is a *potential* citation. The colum `cited` (0 or 1) indicates whether the article was cited or not. Pairs are constrained by species and publication timing (e.g., articles published after ≤6 months after claimant reviews concluded were excluded).

This dataset allows us to evaluate whether claimants cited the available evidence, and whether there was any bias in citation towards articles that found a negative association between cats and prey. We'll do this with binomial model, to test whether the probability of a population study with data being cited (anywhere within citation chain) by claimant sources was different for studies that found a negative association from those that did not find a negative association. 


```{r}
#| eval: true
#| echo: true
#| code-fold: true

# Load data and filter to only claimant sources:

terminus_exploded_filtered <- fread("builds/citation_network/citation_probability.csv")

# Filter to only claimant sources
terminus_exploded_filtered[, making_claim := ifelse(grepl("_claim", 
                                                          cited_by_id), 
                                                    "CLAIM", 
                                                    "NO_CLAIM")]
terminus_exploded_filtered <- terminus_exploded_filtered[making_claim == "CLAIM", ]


m <- glmmTMB(cited ~ in_support + (1|cited_by_id) + (1|scientificName),
             family = binomial(link = "logit"),
             data = terminus_exploded_filtered[grepl("Population", evidence_type_synthetic) &
                                                 has_data == "yes" &
                                                 making_claim == "CLAIM", ])
summary(m)
```
The model summary table here gives a suite of information about the model fit (including AIC, BIC, log-likelihood), the amount of variance explained by each random effect (the claimant source `cited_by_id` and the prey species `scientificName`) and estimates for our coefficients. As you can see, there's no difference between citation probability for articles "in support" (estimate = -0.37, z = -0.859, p = 0.39) (also known as finding a negative association) as for articles that did not (the Intercept).

Now let's plot these probabilities:

out <- terminus_exploded_filtered[grepl("Population", evidence_type_synthetic) &

On average, claimants cited 17% of the available population studies that found a negative association between cats and prey and 23% of available populations studies that did not. All of these citations were made to make the claim that cats were the cause of prey decline.

## Excluded articles {#sec-excluded-articles}

We'll reload the same dataset we used [above](#sec-quantitative-evidence-freq) and we'll do some lumping and splitting of the categories used to classify the article types, simply to make the figure tractable.

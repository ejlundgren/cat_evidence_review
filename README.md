# When consensus procedes the evidence

This repo is associated with 

>Wallach et al 2026. 'When consensus procedes the evidence.' In Submission.

The scripts are organized into two folders: one for pre-processing data (`scripts/1_data_mgmt/`) and one for producing statistics/figures/etc (`scripts/2_analysis/`). 

Helper functions are in the `scripts/functions` directory.

The scripts should be run sequentially (based on numeric prefix) to produce files in the `'builds'` directory or `'figures'` directory.

We also have prepared a website tutorial to walk through the data and code [here](https://ejlundgren.github.io/cat_evidence_review/)

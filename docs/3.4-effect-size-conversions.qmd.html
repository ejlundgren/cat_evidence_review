These effect size formulas are digitized in the function convert_effect_sizes which has them scripted into R code. The formulas are in a side car csv file in the repo located at ‘scripts/functions/conversion_formulas.csv’

Code
source("scripts/functions/convert_effect_sizes.R")

formulas <- fread("scripts/functions/conversion_formulas.csv")

We’ll show the formulas below and demonstrate the use of the function. Note in all cases we will demonstrate with Cohen’s d (an uncorrected estimator of SMD). The function automatically converts Cohen’s d to Hedges’ g, which is the effect size estimator used in our analyses and returned by default from escalc.

SMD ↔︎ lnOR

SMD → lnOR

Let \(yi_{lnOR}\) and \(yi_{d}\) be the point estimate for the lnOR and Cohen’s d effect sizes and \(vi_{lnOR}\) and \(vi_{d}\) be their sampling variances:

\[ \begin{aligned} &yi_{lnOR} = yi_d * \frac{\pi}{\sqrt{3}} \\ &vi_{lnOR} = vi_{d} * \frac{\pi^2}{3} \\ \end{aligned} \]

In R:

Code
convert_effect_sizes(from = "SMD",
                     to = "lnOR",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
This conversion assumes that the continuous data has a logistic distribution. 
Please use conversions carefully and conduct sensitivity analyses. 
Note that the 'vi' is assumed to have been calculated with `metafor::escalc` package defaults (variance of 'd' not 'g') 
   yi_trans   vi_trans
      <num>      <num>
1: 1.677835 0.03289868

lnOR → SMD

To convert from lnOR (\(yi_{lnOR}\)) to Cohen’s \(d\):

\[ \begin{aligned} &yi_d = yi_{lnOR} * \frac{\sqrt{3}}{\pi} \\ &vi_d = vi_{lnOR} * \frac{3}{\pi^2} \\ \end{aligned} \]

In R:

Code
convert_effect_sizes(from = "lnOR",
                     to = "SMD",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
This conversion assumes that the response variable is a discretized version of a continuous variable 
with a logistic distribution for each group (which approximates the normal distribution).
Please use conversions carefully and conduct sensitivity analyses with and without converted data.

      <num>       <num>
1: 0.482765 0.003039636

SMD ↔︎ Zr

SMD → Zr

To convert from SMD to Zr, we first convert \(d\) to the correlation coefficient \(r\) and then to Zr, using a correction factor \(a\) for cases where \(n_1 \neq n_2\). Let \(yi_{Zr}\) and \(yi_d\) be the point estimate for Zr and Cohen’s d:

\[ \begin{aligned} &a = \frac{(n_1 + n_2)^2}{n_1*n_2} \\ &r = \frac{yi_d}{\sqrt{yi_d^2 + a}} \\ &r \leftarrow \min(1, \max(-1, r_i))\\ &yi_{Zr} = atanh(r)\\ \end{aligned} \]

And the sampling variance of Zr (\(vi_{Zr}\)): \[ \begin{aligned} &n = n1 + n2 \\ &vi_{Zr} = \frac{1}{(n - 3)} \\ \end{aligned} \]

In R:

Code
convert_effect_sizes(from = "SMD",
                     to = "Zr",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
This conversion assumes a continuous variable was dichotomized to create the treatment and control groups. 
Note that the 'vi' is assumed to have been calculated with 'metafor::escalc' defaults (variance of 'd' not 'g'). 
Like usual, be careful :) 
    yi_trans   vi_trans
       <num>      <num>
1: 0.4474395 0.03703704

Zr → SMD

First, convert the point estimate of Zr (\(yi_{Zr}\)) to the correlation coefficient \(r\) and calculate the variance of \(r\) (\(vi_r\): \[ \begin{aligned} &r = tanh(yi_{Zr}) \\ &vi_r = \frac{(1-r^2)^2}{(n-1)} \end{aligned} \]

Then calculate the point estimate (\(yi_d\)) and variance (\(vi_d\)) of Cohen’s d:

\[ \begin{aligned} &yi_d = \frac{2*r}{\sqrt{1-r^2}} \\ &vi_d = \frac{4*vi_r}{(1-r^2)^3} \\ \end{aligned} \]

In R:

Code
convert_effect_sizes(from = "Zr",
                     to = "SMD",
                     yi = 0.9,
                     vi = 0.01,
                     n = 50)
'yi' is assumed to be 'Zr' (r-to-z transformed correlation coefficient). 
It may be preferable to supply 'r' and 'n' instead. To do so specify 'r' in the 'from' argument and provide a vector of correlation coefficients named 'r'. 
This conversion assumes that the underlying data was continuous with a bivariate normal distribution, with the two groups created by dichotomozing one of the two variables. 
Please use conversions carefully and conduct sensitivity analyses

We'll show the formulas below and demonstrate the use of the function. Note in all cases we will demonstrate with Cohen's d (an uncorrected estimator of SMD). The function automatically converts Cohen's d to Hedges' g, which is the effect size estimator used in our analyses and returned by default from `escalc`.

# SMD ↔ lnOR 

## SMD → lnOR {#sec-smd-lnOR}

Let $yi_{lnOR}$ and $yi_{d}$ be the point estimate for the lnOR and Cohen's d effect sizes and $vi_{lnOR}$ and $vi_{d}$ be their sampling variances:

$$
\begin{aligned}
&yi_{lnOR} = yi_d * \frac{\pi}{\sqrt{3}} \\
&vi_{lnOR} = vi_{d} * \frac{\pi^2}{3} \\
\end{aligned}
$$

In R:

```{r}
#| eval: true
#| echo: true
#| out-width: "70%"
convert_effect_sizes(from = "SMD",
                     to = "lnOR",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)

```


## lnOR → SMD {#sec-lnOR-smd}
To convert from lnOR ($yi_{lnOR}$) to Cohen's $d$:

$$
\begin{aligned}
&yi_d = yi_{lnOR} * \frac{\sqrt{3}}{\pi} \\
&vi_d = vi_{lnOR} * \frac{3}{\pi^2} \\
\end{aligned}
$$

In R:
```{r}
#| eval: true
#| echo: true
#| out-width: "70%"
convert_effect_sizes(from = "lnOR",
                     to = "SMD",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
```

# SMD ↔ Zr
## SMD → Zr {#sec-smd-zr}

To convert from SMD to Zr, we first convert $d$ to the correlation coefficient $r$ and then to Zr, using a correction factor $a$ for cases where $n_1 \neq n_2$. Let $yi_{Zr}$ and $yi_d$ be the point estimate for Zr and Cohen's d:

$$
\begin{aligned}
&a = \frac{(n_1 + n_2)^2}{n_1*n_2} \\
&r = \frac{yi_d}{\sqrt{yi_d^2 + a}} \\
&r \leftarrow \min(1, \max(-1, r_i))\\
&yi_{Zr} = atanh(r)\\
\end{aligned}
$$

And the sampling variance of Zr ($vi_{Zr}$):
$$
\begin{aligned}
&n = n1 + n2 \\
&vi_{Zr} = \frac{1}{(n - 3)} \\
\end{aligned}
$$

In R:
```{r}
#| eval: true
#| echo: true
#| out-width: "70%"
convert_effect_sizes(from = "SMD",
                     to = "Zr",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
```


## Zr → SMD {#sec-zr-smd}
First, convert the point estimate of Zr ($yi_{Zr}$) to the correlation coefficient $r$ and calculate the variance of $r$ ($vi_r$:
$$
\begin{aligned}
&r = tanh(yi_{Zr}) \\
&vi_r = \frac{(1-r^2)^2}{(n-1)}
\end{aligned}
$$

Then calculate the point estimate ($yi_d$) and variance ($vi_d$) of Cohen's d:

$$
\begin{aligned}
&yi_d = \frac{2*r}{\sqrt{1-r^2}} \\
&vi_d = \frac{4*vi_r}{(1-r^2)^3} \\
\end{aligned}
$$

In R:
```{r}
#| eval: true
#| echo: true
#| out-width: "70%"
convert_effect_sizes(from = "Zr",
                     to = "SMD",
                     yi = 0.9,
                     vi = 0.01,
                     n = 50)

```

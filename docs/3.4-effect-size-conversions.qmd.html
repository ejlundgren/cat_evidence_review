Appendix: effect size conversion formulas

Published

We converted the effect sizes into common types based on the formulas in (Borenstein et al. 2021), which we digitized in our function convert_effect_sizes. The formulas are in an executable sidecar csv file in the repo located at ‘scripts/functions/conversion_formulas.csv’

Code
source("scripts/functions/convert_effect_sizes.R")

formulas <- fread("scripts/functions/conversion_formulas.csv")

We’ll show the formulas below, demonstrate the use of the function, and the digitized R formulas.

Important

Note that in all cases, the conversion formulas below are based on conversions from Cohen’s d (the uncorrected estimator of SMD). As such, SMD estimates had to first be transformed to Cohen’s d, and the outputs of conversions had to be transformed to Hedges’ g. Converting from Hedges’ g (the default estimator returned from escalc) is done as follows, with \(n_1\), \(n_2\) equivalent to the sample sizes of groups 1 and 2, \(yi_g\) and \(yi_d\) the effect size point estimate sfor Hedges’ g and Cohen’s d, and \(J\) a small-sample bias correction factor.

\[ \begin{aligned} &J = 1 - \frac{3}{4 * (n_1 + n_2 - 2) - 1} \\ \end{aligned} \tag{1}\]

\[ \begin{aligned} &yi_d = \frac{yi_g}{J} \\ \end{aligned} \tag{2}\]

\[ \begin{aligned} &yi_g = J * yi_d \\ \end{aligned} \tag{3}\]

Note that the estimator of sampling variance for SMD, following escalc, is Cohen’s d’s sampling variance estimator and thus did not need to be converted with \(J\).

SMD ↔︎ lnOR

SMD → lnOR

Let \(yi_{lnOR}\) and \(yi_{d}\) be the point estimate for the lnOR and Cohen’s d effect sizes and \(vi_{lnOR}\) and \(vi_{d}\) be their sampling variances. The resulting estimate of Cohen’s d was then converted using Equation 3 to Hedges’ g.

\[ \begin{aligned} &yi_{lnOR} = yi_d * \frac{\pi}{\sqrt{3}} \\ &vi_{lnOR} = vi_d * \frac{\pi^2}{3} \\ \end{aligned} \tag{4}\]

In R:

Code
convert_effect_sizes(from = "SMD",
                     to = "lnOR",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
This conversion assumes that the continuous data has a logistic distribution. 
Please use conversions carefully and conduct sensitivity analyses. 
Note that the 'vi' is assumed to have been calculated with `metafor::escalc` package defaults (variance of 'd' not 'g') 
   yi_trans   vi_trans
      <num>      <num>
1: 1.677835 0.03289868

Now let’s look at the transcribed formula for the point estimate conversion. yi and vi refer to the original effect size and sampling variance estimates (in this case of lnOR) and yi_trans and vi_trans refer to the converted estimates (in this case of SMD), n1 and n2 = \(n_{1, 2}\), and d = \(yi_d\). Note that our formula for \(J\) uses the gamma distribution instead of \(J = 1 - \frac{3}{4 * (n_1 + n_2 - 2) - 1}\):

[1] "J <- ifelse((n1 + n2 - 2) <= 1, NA_real_, exp(lgamma((n1 + n2 - 2)/2) - log(sqrt((n1 + n2 - 2)/2)) - lgamma(((n1 + n2 - 2) - 1)/2)))"
[2] "d <- yi / J"                                                                                                                         
[3] "yi_trans <- d * (pi / sqrt(3))"

And for sampling variance:

[1] "vi_trans <- vi * (pi^2/3)"

lnOR → SMD

To convert from lnOR (\(yi_{lnOR}\)) to Cohen’s \(d\):

\[ \begin{aligned} &yi_d = yi_{lnOR} * \frac{\sqrt{3}}{\pi} \\ &vi_d = vi_{lnOR} * \frac{3}{\pi^2} \\ \end{aligned} \tag{5}\]

\(yi_d\) was then converted to Hedges’ g using Equation 3.

In R:

Code
convert_effect_sizes(from = "lnOR",
                     to = "SMD",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
This conversion assumes that the response variable is a discretized version of a continuous variable 
with a logistic distribution for each group (which approximates the normal distribution).
Please use conversions carefully and conduct sensitivity analyses with and without converted data. 
   yi_trans    vi_trans
      <num>       <num>
1: 0.482765 0.003039636

And the transcribed formulas in R:

[1] "d <- yi * (sqrt(3)/pi)"                                                                                              
[2] "J <- ifelse((n1+n2-2) <= 1, NA_real_, exp(lgamma((n1+n2-2)/2) - log(sqrt((n1+n2-2)/2)) - lgamma(((n1+n2-2) - 1)/2)))"
[3] "yi_trans <- J * d"

And for sampling variance:

[1] "vi_trans <- vi * (3/pi^2)"

The variable names are the same as above.

SMD ↔︎ Zr

SMD → Zr

To convert from SMD to Zr, we used Equation 2 to convert Hedges’ g to Cohen’s d. We then converted \(yi_d\) to the correlation coefficient \(r\) and then to Zr, using a correction factor \(a\), to account for cases where \(n_1 \neq n_2\). Let \(yi_{Zr}\) and \(yi_d\) be the point estimate for Zr and Cohen’s d:

\[ \begin{aligned} &a = \frac{(n_1 + n_2)^2}{n_1*n_2} \\ &r = \frac{yi_d}{\sqrt{yi_d^2 + a}} \\ &r \leftarrow \min(1, \max(-1, r_i))\\ &yi_{Zr} = atanh(r)\\ \end{aligned} \tag{6}\]

And the sampling variance of Zr (\(vi_{Zr}\)): \[ \begin{aligned} &n = n1 + n2 \\ &vi_{Zr} = \frac{1}{(n - 3)} \\ \end{aligned} \tag{7}\]

In R:

Code
convert_effect_sizes(from = "SMD",
                     to = "Zr",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)
This conversion assumes a continuous variable was dichotomized to create the treatment and control groups. 
Note that the 'vi' is assumed to have been calculated with 'metafor::escalc' defaults (variance of 'd' not 'g'). 
Like usual, be careful :) 
    yi_trans   vi_trans
       <num>      <num>
1: 0.4474395 0.03703704

And let’s look at the R formulas. yi and vi refer to the original effect size and sampling variance estimates (in this case of SMD) and yi_trans and vi_trans refer to the converted estimates (in this case of Zr), n1 and n2 = \(n_{1, 2}\), a = the correction factor \(a\), and d = \(yi_d\). Note that our formula for \(J\) uses the gamma distribution instead of \(J = 1 - \frac{3}{4 * (n_1 + n_2 - 2) - 1}\):

[1] "J <- ifelse((n1 + n2 - 2) <= 1, NA_real_, exp(lgamma((n1 + n2 - 2)/2) - log(sqrt((n1 + n2 - 2)/2)) - lgamma(((n1 + n2 - 2) - 1)/2)))"
[2] "d <- yi / J"                                                                                                                         
[3] "a <- (n1 + n2)^2 / (n1 * n2)"                                                                                                        
[4] "r <- d/sqrt(d^2 + a)"                                                                                                                
[5] "yi_trans <- atanh(r)"

And for sampling variance:

[1] "N <- n1 + n2"          "vi_trans <- 1 / (N-3)"

Zr → SMD

First, convert the point estimate of Zr (\(yi_{Zr}\)) to the correlation coefficient \(r\) and calculate the variance of \(r\) (\(vi_r\)): \[ \begin{aligned} &r = tanh(yi_{Zr}) \\ &vi_r = \frac{(1-r^2)^2}{(n-1)} \end{aligned} \tag{8}\]

Then calculate the point estimate (\(yi_d\)) and variance (\(vi_d\)) of Cohen’s d:

\[ \begin{aligned} &yi_d = \frac{2*r}{\sqrt{1-r^2}} \\ &vi_d = \frac{4*vi_r}{(1-r^2)^3} \\ \end{aligned} \tag{9}\]

Cohen’s d (\(yi_d\)) was then converted to Hedges’ g following Equation 3.

In R:

Code
convert_effect_sizes(from = "Zr",
                     to = "SMD",
                     yi = 0.9,
                     vi = 0.01,
                     n = 50)
'yi' is assumed to be 'Zr' (r-to-z transformed correlation coefficient). 
It may be preferable to supply 'r' and 'n' instead. To do so specify 'r' in the 'from' argument and provide a vector of correlation coefficients named 'r'. 
This conversion assumes that the underlying data was continuous with a bivariate normal distribution, with the two groups created by dichotomozing one of the two variables. 
Please use conversions carefully and conduct sensitivity analyses 
   yi_trans vi_trans
      <num>    <num>
1: 2.037275 0.167652

And here are the transcribed formulas used:

[1] "r <- tanh(yi)"                                                                                                       
[2] "d <- (2*r) / sqrt(1-r^2)"                                                                                            
[3] "J <- ifelse((2*n - 2) <= 1, NA_real_, exp(lgamma((2*n - 2)/2) - log(sqrt((2*n - 2)/2)) - lgamma(((2*n - 2) - 1)/2)))"
[4] "yi_trans <- d * J"

And for sampling variance:

[1] "r <- tanh(yi)"                    "vi_r <- (1 - r^2)^2 / (n-1)"     
[3] "vi_trans <- (4*vi_r) / (1-r^2)^3"

The variable names are the same as above.

# SMD ↔ lnOR 

## SMD → lnOR {#sec-smd-lnOR}

Let $yi_{lnOR}$ and $yi_{d}$ be the point estimate for the lnOR and Cohen's d effect sizes and $vi_{lnOR}$ and $vi_{d}$ be their sampling variances. The resulting estimate of Cohen's d was then converted using @eq-3 to Hedges' g. 


$$
\begin{aligned}
&yi_{lnOR} = yi_d * \frac{\pi}{\sqrt{3}} \\
&vi_{lnOR} = vi_d * \frac{\pi^2}{3} \\
\end{aligned}
$${#eq-4}

In `R`:

```{r}
#| eval: true
#| echo: true
#| out-width: "70%"
convert_effect_sizes(from = "SMD",
                     to = "lnOR",
                     yi = 0.9,
                     vi = 0.01,
                     n1 = 15,
                     n2 = 15)

```


Now let's look at the transcribed formula for the point estimate conversion. `yi` and `vi` refer to the original effect size and sampling variance estimates (in this case of lnOR) and `yi_trans` and `vi_trans` refer to the converted estimates (in this case of SMD), `n1` and `n2` = $n_{1, 2}$, and `d` = $yi_d$. Note that our formula for $J$ uses the gamma distribution instead of $J = 1 - \frac{3}{4 * (n_1 + n_2 - 2) - 1}$:

```{r}

#| eval: true

```

# SMD ↔ Zr
## SMD → Zr {#sec-smd-zr}

To convert from SMD to Zr, we used @eq-2 to convert Hedges' g to Cohen's d. We then converted $yi_d$ to the correlation coefficient $r$ and then to Zr, using a correction factor $a$, to account for cases where $n_1 \neq n_2$. Let $yi_{Zr}$ and $yi_d$ be the point estimate for Zr and Cohen's d:

$$
\begin{aligned}
&a = \frac{(n_1 + n_2)^2}{n_1*n_2} \\
&r = \frac{yi_d}{\sqrt{yi_d^2 + a}} \\
&r \leftarrow \min(1, \max(-1, r_i))\\
&yi_{Zr} = atanh(r)\\
\end{aligned}
$${#eq-6}

And the sampling variance of Zr ($vi_{Zr}$):
$$
\begin{aligned}
&n = n1 + n2 \\
&vi_{Zr} = \frac{1}{(n - 3)} \\
\end{aligned}
$${#eq-7}

```{r}
                     to = "Zr",

                     n2 = 15)
```

## Zr → SMD {#sec-zr-smd}
First, convert the point estimate of Zr ($yi_{Zr}$) to the correlation coefficient $r$ and calculate the variance of $r$ ($vi_r$):
$$
\begin{aligned}
&r = tanh(yi_{Zr}) \\
&vi_r = \frac{(1-r^2)^2}{(n-1)}
\end{aligned}
$${#eq-8}

Then calculate the point estimate ($yi_d$) and variance ($vi_d$) of Cohen's d:

$$
\begin{aligned}
&yi_d = \frac{2*r}{\sqrt{1-r^2}} \\
&vi_d = \frac{4*vi_r}{(1-r^2)^3} \\
\end{aligned}
$${#eq-9}

Cohen's d ($yi_d$) was then converted to Hedges' g following @eq-3.
